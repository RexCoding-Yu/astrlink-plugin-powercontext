# PowerContext 记忆

AstrLink 的插件，把 [PowerContext](https://github.com/oceanbase/powercontext)
记忆服务器接进网关：

- 会话有了项目，就把这个项目的画像和最近更新的主题目录放进系统提示词，会话内不变。
- 新会话还没有项目时，只在第一轮问一次要纳入哪个项目，并列出已有的项目；同一个目录里的新会话自动接上上次的项目。
- 每轮结束时把用户输入的文字写进 PowerContext；会话定下项目之前的几轮，定下后补写。整理成记忆、生成画像由服务器定时完成。
- 客户端和网关在同一台电脑上、能执行 shell 时，Agent 可以自己检索这个项目的记忆、读主题全文、列项目，也可以把值得记住的项目信息主动上报。
- 插件页显示服务器的版本、自动整理的状态和最近一次写入；「测试连接」检查地址和令牌。

这不是 PowerContext 官方的插件：它只用 PowerContext 公开的 HTTP 接口，不包含 PowerContext 的代码。

## 要求

- AstrLink：带插件平台 v2 的版本（插件用 `apiVersion: 2`）。
- PowerContext 服务器 1.3 或以上。1.3 和 1.4 实际跑过；更新的版本只要接口不变就能用，插件页会注明「这个版本没有验证过」。

## 安装

1. 在 AstrLink 的「插件」页点「安装插件」，粘贴本仓库的地址
   `https://github.com/RexCoding-Yu/astrlink-plugin-powercontext`。
2. AstrLink 从源码构建，显示审查结果（来源、版本、申请的能力、联网用途），在「插件确认」窗口里确认后安装。
3. 装好的插件不会自动启用：在它的设置里填服务器地址和令牌并保存（访问新地址要在确认窗口里允许），然后启用。

以后在插件页点「检查更新」就能看到这个仓库的新版本。

## 设置

| 分组 | 设置项                                   | 说明                                                           |
| ---- | ---------------------------------------- | -------------------------------------------------------------- |
| 连接 | 服务器地址、令牌                         | 插件只访问这个地址，令牌也只发往这里                           |
| 装载 | 装载画像和主题目录、主题目录条数         | 会话定下项目后放进系统提示词的内容，默认列最近更新的 20 个主题 |
| 会话 | 没有项目时询问、询问时列出几个项目       | 列出的项目名会随询问发给上游模型                               |
| 查询 | 原子记忆、主题、经验、技能、每次返回条数 | Agent 检索时查哪几类记忆、最多返回几条                         |
| 上报 | 允许 Agent 上报                          | 关掉后 Agent 只能查，不能写                                    |

会话绑定、客户端范围、等待时间、Agent 查询、隐私检查这些通用设置由 AstrLink 提供，和插件自己的设置排在一起。

## 开发

需要 AstrLink 自带的 `astrlink` 命令：

```sh
astrlink plugin test    # 跑 tests/ 里的用例
astrlink plugin check   # 按 AstrLink 加载的方式检查清单、能力和钩子
astrlink plugin dev     # 构建并装进本机运行中的 AstrLink，改了自动重新加载
```

`tests/`
里的每个文件是一个场景：伪造的 PowerContext 应答（`fetch`）、调用前后的存储，以及钩子应当返回的结果。写了
`times` 的应答必须正好请求这么多次，写了 `body`
的要求请求正文包含这些字段。时钟固定在 `2026-10-21T22:30:00Z`，时区是
`America/New_York`。插件的输出改了，按失败信息里的 `returned` 更新对应用例的
`expect` 即可。

`astrlink-plugin.d.ts`
是插件接口的类型定义，来自 AstrLink；编辑器靠它补全和检查，`tsc -p .`
可以做一次类型检查。
